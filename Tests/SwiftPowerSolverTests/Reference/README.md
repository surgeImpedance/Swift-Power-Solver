# pandapower reference dumps

Generated by `Tools/dump_reference.py` with any Python that has
[pandapower](https://www.pandapower.org) installed:

    python Tools/dump_reference.py

Each JSON holds, for one IEEE case, full precision:
ppc-level bus/branch/gen parameters (already per-unit), pandapower's own Ybus
as sparse triplets, and the solved bus voltages/angles + branch flows —
with and without generator Q-limit enforcement.

The Swift tests diff `YbusBuilder` / `NewtonRaphsonSolver` output against
these files. They are checked in so `swift test` works from a bare clone
with no Python installed; regenerate only when changing the dump script or
bumping pandapower.
